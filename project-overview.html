// technical_highlights

PIPELINE
Shared Directory Contract
Shared directory path is the only contract between the two scripts. A missing plant file adds it to file_missing and continues — a mid-week download failure never touches Friday's run.
MATCHING
One Pass, Two Outputs
After the IBD loop, residual osd_work is the OVG-new set — no second scan. _match_and_consume() drops matched OSD rows as each IBD row is processed, producing both missing and OVG-new in one pass.
OVG
Cross-Week Deduction
Same consume logic runs against the OVG file before generating the report — matched items deducted from missing. Pruning: (current_week − row_week) % 52 > 15 — modulo handles year-boundary so week 3 and week 51 compute as 4 weeks apart, not −48.
VALIDATION
Non-Blocking, Header-Aware
read_excel(nrows=10) scans the first 10 rows for the 'O/S/D' header — row 1 is never assumed. Validation failures flag to file_issues and surface in the daily email without blocking the file or Friday's run.
SCHEMA
Normalize at Read, Not at Match
{col.strip().lower(): col} lookup + 'serial number' in cl substring match normalize all variants at read. Final slice to OSD_COLS drops extras including trailing Unnamed:*. Matching logic downstream sees one consistent schema.
EMAIL
Per-Plant Isolation
Each plant runs in its own try/except — one failure never blocks others. Email sent only when has_report=True; zero-missing plants generate no email. PLANT_RECIPIENTS maps independent {to, cc, bcc} per plant.

// error_handling

Missing OS&D File
Plant skipped, added to file_missing. Other plants continue unaffected.
File Validation Failure
Issue logged to file_issues and reported in the download status email. Processing continues with other files.
IBD File Not Found
FileNotFoundError raised. IBD is required — Friday's main.py exits early and logs file_missing.
Per-Plant Processing Error
Each plant wrapped in try/except. One plant failure never blocks others — logged to result.fail.
Column Mismatch
Variant names (SERIAL NUMBERS, PLANT) normalized via .strip().lower(). Unnamed extras silently dropped.
SMTP / POP3 Failure
Connection error logged with traceback, returns False. Failure alert sent with log snippet if main processing errors occur.

Column Schema Normalization main_example.py 
# Normalize all OSD files to fixed 13-col schema
# Handles: 'PLANT', 'Unnamed:13', 'SERIAL NUMBERS'
col_lower = {
    str(c).strip().lower(): c
    for c in df.columns
}
rename_map = {}
for target in OSD_COLS:
    tl = target.lower()
    if tl in col_lower:
        rename_map[col_lower[tl]] = target
    elif target == 'Serial Number(s)':
        # substring match for spelling variants
        found = next((
            c for cl, c in col_lower.items()
            if 'serial number' in cl
        ), None)
        if found:
            rename_map[found] = target
df = df.rename(columns=rename_map)
df = df[[c for c in OSD_COLS if c in df.columns]]

5-Week File Retention — Auto Cleanup report_downloader_example.py 
# Week number extracted from filename (W## / WK##)
# % 52 handles correct wrap at year boundary
def _cleanup(directory, pattern, keep):
    if not directory.exists():
        return
    current_week = datetime.today().isocalendar()[1]
    for f in directory.iterdir():
        if not f.is_file():
            continue
        m = re.search(pattern, f.name, re.IGNORECASE)
        if not m:
            continue
        file_week = int(m.group(1))
        if (current_week - file_week) % 52 > keep:
            f.unlink()

# OSD: W##, IBD: WK##, missing reports: W##
_cleanup(OSD_DIR,     r'W(\d+)',  KEEP_WEEKS)
_cleanup(IBD_DIR,     r'WK(\d+)', KEEP_WEEKS)
_cleanup(MISSING_DIR, r'W(\d+)',  KEEP_WEEKS)

// dev_process · Claude Code Conversations

Two-stage contract: DownloadResult as interface
TJ
Two independent scripts, shared directory path as the only contract. In the scan loop, track found plants with a set — guard with plant not in found_plants so the same plant can't be saved twice across multiple matching emails. Fetch headers first with top(idx, 0) — only commit to retr() for the full email body when there's an actual subject match. Carry everything downstream needs in a DownloadResult dataclass: downloaded_osd, missing_osd, received_times, file_issues, error. That struct is the full interface — no shared mutable state between the two scripts.
C
_fetch_headers() calls top(idx, 0), _fetch_email() calls retr() — full download only fires on a subject match. found_plants: set accumulates in the scan loop; the break after a plant match exits the inner plant loop since one email maps to one plant. DownloadResult is returned from download() and consumed directly in report_downloader.py — the dataclass is the only handoff.
Consume loop: tuple return, default=1, two outputs
TJ
Pass osd_work = osd.copy() into the loop — never mutate the original. _match_and_consume() returns tuple[int, pd.DataFrame]: remaining qty and the updated working set in one shot. Serial Number(s): match by astype(str).str.strip(), drop those indices, return 0, osd_work. Model fallback: collect all matching model indices, sum their qty with _to_int(val, default=1) — default is 1, not 0, so a parse failure never silently skips an item. After the IBD loop, whatever's left in osd_work is the OVG-new set. One pass, two outputs.
C
find_new_missing() re-assigns osd_work on every _match_and_consume() call — threads through the full IBD loop. _to_int(default=1) is the safety net: empty or non-numeric Qty cells still count as 1 missing item. The final osd_work returned alongside missing_df goes directly into save_ovg() as new OVG entries — no second scan needed.
OVG: first-run schema, per-plant split, % 52 prune
TJ
load_ovg_for_plant() returns pd.DataFrame(columns=OSD_COLS) when the file doesn't exist — same schema on first run, no special-casing downstream. In save_ovg(): filter existing[plant_col != plant] to isolate other plants' rows, concat with this plant's updated block, write the full file back. Enforce ovg_new[OSD_COLS].copy() at write — not at read. Prune with (current_week_num − int(w)) % 52 <= 15 — the modulo handles year rollover so week 3 and week 51 compute as 4 weeks apart, not −48.
C
Empty OVG DataFrame with OSD_COLS on first run — check_missing_against_ovg() early-returns on ovg.empty, clean with no branching. Per-plant split in save_ovg() preserves all other plants on every write. % 52 in pruning is the load-bearing line: without it, early-January weeks incorrectly flag December data as outside the 15-week retention window.
Normalize at read: col_lower dict + substring match
TJ
Build col_lower = {str(c).strip().lower(): c for c in df.columns} at read — key is normalized, value is the original column name, used directly for the rename map. For Serial Number(s), don't exact-match: do 'serial number' in cl substring to catch Serial Numbers, SERIAL NUMBER(S), any variant. Then df[[c for c in OSD_COLS if c in df.columns]] — that single slice enforces column order AND drops all extras including trailing Unnamed:*. Enforce the same OSD_COLS slice in save_ovg() at write: ovg_new[OSD_COLS].copy() so the OVG file never accumulates naming drift.
C
Rename map built per-file inside load_osd_damage_rows(). D-row filter uses str.upper().isin(['D', 'DAMAGE']) — handles plants that spell out "DAMAGE" instead of just "D". The ordered slice [c for c in OSD_COLS if c in df.columns] is deterministic: same column order regardless of source file layout. OSD_COLS at save_ovg() write means the OVG file stays clean across all weeks and plants.
